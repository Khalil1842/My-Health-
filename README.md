# MY HEALTH (Android PWA)

Aplikasi rekod kesihatan peribadi berbahasa Melayu.

## Cara guna di Android
1. Muat naik/hos folder ini ke laman HTTPS (contohnya GitHub Pages atau hosting sendiri).
2. Buka URL laman itu menggunakan Chrome Android.
3. Tekan menu tiga titik > **Add to Home screen** atau **Install app**.
4. Buka MY HEALTH dari ikon skrin utama.

PWA memerlukan HTTPS (atau localhost) untuk pemasangan dan service worker. Fail ini belum menjadi APK native dan belum diterbitkan ke Google Play.

## Fungsi
- Rekod berat, tekanan darah, gula dan simptom.
- Sejarah rekod harian.
- Graf trend berat badan.
- Rekod keputusan ujian darah (creatinine, eGFR, uric acid, LDL, HbA1c).
- Eksport CSV dan backup/pulih JSON.
- Data disimpan secara setempat dalam browser/peranti.

## Privasi & batasan
Data berada dalam localStorage browser. Ia tidak disulitkan atau disegerakkan ke cloud. Jangan gunakan pada peranti kongsi; lindungi telefon dan buat backup. Memadam data laman/browser boleh memadam rekod. Aplikasi ini bukan alat diagnosis atau pengganti nasihat doktor.

## Ujian
Buka `index.html` untuk pratonton asas. Untuk pemasangan PWA penuh, gunakan hosting HTTPS.
